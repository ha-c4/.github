# ha-c4/.github

Organization-wide files for [ha-c4 (Home Assistant + Control4)](https://github.com/ha-c4), a community effort to combine the various forks into one place for Control4 integration in Home Assistant.

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | Public profile shown on the [ha-c4 organization page](https://github.com/ha-c4) |
| [AGENTS.md](AGENTS.md) | Guidelines for contributors and AI agents, including commit messages |
| [CLAUDE.md](CLAUDE.md) | Points Claude Code at AGENTS.md |

ha-c4 is an independent project and is not affiliated with Home Assistant or Control4.
